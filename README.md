# Code / Video 社区作品画廊

收集创作者公开发布、提示词明确要求制作或录制视频的社区案例。网页提供站内播放器、中文提示词、素材说明与来源链接。

## 使用

直接打开 `index.html`，或在项目目录运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。视频和播放器依赖网络；HLS 视频在 Safari 使用原生播放，其余浏览器通过 CDN 加载 hls.js。原视频可能受第三方服务、网络与版权限制而无法播放。

## 收录原则

作品、视频和提示词分别归原作者和相关权利人所有。对于未公开的提示词或素材，不推测、不伪造；每项保留来源。当前数据来自 [Awesome Fable 5.5 Videos](https://github.com/yihui-dev/awesome-fable5-5-videos) 和 [Remotion Prompt Showcase](https://www.remotion.dev/prompts)。翻译仅供参考，原文以来源为准。

## 协议

网站代码采用 MIT 协议；协议不覆盖第三方视频、提示词、音乐、素材及商标。请自行核对各自权利与使用条件。
